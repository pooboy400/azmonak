# core — هستهٔ الگوریتمی آزمونک

قلب هوش سیستم: هر عددی که آزمونک به دانش‌آموز نشان می‌دهد از همین شش ماژول بیرون می‌آید.
این پکیج **پایتون خالص** است — بدون I/O، بدون دیتابیس، بدون هیچ وابستگی خارجی (پایتون ۳٫۱۰ به بالا).
همین تفکیک «الگوریتم از رابط» همان چیزی است که سند دفاعی به داور وعده داده است.

## نقشهٔ ماژول‌ها

| فایل | موتور | تصمیم مرتبط |
|---|---|---|
| `elo.py` | رتبه‌بندی دوطرفهٔ Elo (توان دانش‌آموز / سختی سؤال) | پیوست الف |
| `placement.py` | جایابی ۴ سؤالی تازه‌وارد با ترتیب سختی پراکنده | D1 |
| `selector.py` | انتخاب سؤال: ناحیهٔ هدف ۶۵–۷۵٪ + ارزش آموزشی + محدودیت مواجهه | G8 |
| `leveling.py` | نردبان سطح ۱–۳ هر دسته + هشدار مطالعه | D16 |
| `sm2.py` | مرور فاصله‌دار SM-2 با کیفیت سه‌سیگنالی (درستی، اعتماد، تأخیر) | D10، D14 |
| `predict.py` | نمرهٔ وزن‌دار جلسه + پیش‌بینی روند با λ=۰٫۸۵ | D13 |

## اجرای تست‌های طلایی

همهٔ مثال‌های عددی کتاب سه‌لایه با این تست‌ها بازتولید می‌شوند (۱۲۲۲٫۵/۱۳۴۴٫۴، زنجیرهٔ ۱→۶→۱۵، نمرهٔ ۷۲/۵۶، پیش‌بینی ۶۱٫۴/۶۳٫۸ و...):

```bash
# با pytest (از ریشهٔ مخزن):
python3 -m pytest core/tests -q

# یا مستقیم (بدون هیچ نصبی):
python3 core/tests/test_core.py
```

## استفاده در کد

از ریشهٔ مخزن، بدون هیچ نصبی:

```python
from core.elo import apply_result
print(apply_result(1200, 1350, True))   # (1222.51..., 1344.37..., 0.2966...)
```

یا به‌صورت پکیج نصب‌شونده (برای backend در گام ۲):

```bash
pip install -e ./core    # ترجیحاً داخل venv
```

## قواعد این پکیج

- کد و نام متغیرها انگلیسی، docstringها فارسی (تصمیم D5).
- هر ماژول بالای فایل یک بخش «دستگیره‌های قابل تنظیم» دارد — همهٔ اعداد سیاست این‌جاست، شکارِ عدد در لابه‌لای منطق ممنوع.
- هیچ ماژولی چیزی از دیگری جز فرمول‌های Elo نمی‌داند؛ وابستگی‌ها فقط `from .elo import ...` است.
- تغییر هر دستگیره باید تست طلایی را سبز نگه دارد؛ اگر خراب شد، یعنی سند و کد از هم جدا شده‌اند — یکی را اصلاح کن.
